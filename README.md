# Multi-Step Auth Form

A modern authentication UI built using React, TypeScript, React Hook Form, and Zod.

---

## 🚀 Features

- Login Form
- Signup Form
- Multi-Step Signup
- Conditional Fields
- Form Validation with Zod
- React Hook Form Integration
- Protected Routes
- Dashboard Page
- Dark Mode
- Toast Notifications
- Axios API Calls
- Loading States
- LocalStorage Authentication
- Responsive UI

---

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Hook Form
- Zod
- Axios
- React Router DOM
- React Hot Toast

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into project folder:

```bash
cd multistep-auth-form
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

---

## 🔐 Authentication Flow

- User logs in using form validation
- Data stored in LocalStorage
- Protected Dashboard route
- Unauthorized users redirected to Home page
- Logout removes authentication

---

## 🌙 Dark Mode

- Toggle between light and dark mode
- Theme saved in LocalStorage
